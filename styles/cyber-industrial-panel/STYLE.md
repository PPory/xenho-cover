# 赛博工业面板

## 视觉风格原子

创作一张「赛博工业面板」风格的封面。风格核心：纯黑打底，多档黑度的装甲面板以 45° 折角互相咬合分层，浅灰电路走线在黑暗里画出结构，一枚放射刻度圆元素做全画面唯一的圆。气质冷静、精密、克制——是工业设计图纸和 HUD 界面的未来感，不是霓虹赛博朋克的热闹。哑光、平涂、无光效。

## 色彩系统

严格单色灰阶，无任何彩色、无渐变、无发光：

- 底：纯黑 `#000000`
- 面板三档：`#101010` / `#181818` / `#282828`——黑度差异微妙但可辨，靠它区分装甲板层次
- 亮色：浅灰 `#D9D8DA`——走线、文字、放射元素、细节点缀
- **亮色总占比控制在 5–8%**：黑色绝对主导，亮的地方才是被看的地方

## 面板与走线系统（核心）

- **装甲面板分层**：三档深灰面板互相叠压咬合，每块面板的轮廓由水平线、垂直线和 45° 斜切组成——45° 折角是唯一的转角语言，全画面无曲线、无圆角（放射圆元素除外）。
- **电路走线**：浅灰线条分粗细两级，沿水平和 45° 方向布线，像 PCB 走线或机甲管线；走线沿面板边缘行进、在折角处转向，线端可收在一个焊点圆点或小方块上。走线必须有结构逻辑（从哪来、到哪去），不是随机装饰。
- **放射刻度圆**：全画面唯一的圆形元素——外圈放射状刻度线，中心一个实心圆承载一个符号（×、箭头、或与主题相关的极简符号），像一枚仪表或按钮。位置压在构图重心上。
- **技术细节点缀**（选 3–5 处，克制）：斜线排线块、锯齿边缘、阶梯形、十字对位标、小三角箭头、序号数字。这些细节让画面像一张真实的工业图纸。

## 图文关系

- 主标题：粗黑体，浅灰 `#D9D8DA`，横排或竖排（竖排更像原生海报），落在最上层面板的干净区域，汉字完整精确、清晰可读，不做发光、描边、透视变形。
- 副标题：极小号等宽字体文字块，两端对齐排成一个小方块，贴在某块面板上，像系统界面的标注文字。
- 可加 1–2 处装饰性小字（序号、短标签），但不携带真实信息、不出现随机英文句子。
- 文字总量克制：主标题 + 一个副标题块 + 至多两处点缀小字。

## 风格特有禁用项

- 不要霓虹、发光、辉光、渐变、蓝紫色光效——本风格是哑光单色的。
- 不要曲线和圆角面板，唯一的圆是放射刻度元素。
- 不要亮色面积失控——画面变灰就失去了「黑暗里亮出关键」的张力。
- 不要具象插画、机器人、人物形象。
- 不要无结构的杂乱走线。
- 不要把 NKH 或任何真实工作室、品牌的名称画进图。
