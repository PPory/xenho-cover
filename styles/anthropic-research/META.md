```yaml
  - 主插画默认承载在大型浅色（#EFEAE0）不规则有机形色块上（占画面 20–35%，可出血），内部为黑色手绘线稿（#1A1A1A）
  - 有机色块装饰系统：3–6 个，总面积 8–15%，必须有大小对比（中大型出血色块 + 小圆点/小方块/纸张形/点阵/波浪线）
  - 可选左上角等宽字体小标签 + 强调色短横线
  - 衬线主标题（Source Han Serif / Georgia 质感），辅助文字用 Inter 类无衬线，标签注释用 JetBrains Mono 等宽
cover_shape_adaptation:
  - 横版（2.35:1 / 5:2 / 16:9）：左字右图——标题居左留白区，大型有机色块承载插画居右，装饰色块沿对角分布
  - 竖版（3:4 / 4:5 / 9:16）：标题主导，插画色块紧凑居中下，装饰取密度下限
  - 主标题必须完整落在纯色底留白处，作为版面结构中心
  - 副标题至多一行，用无衬线小字贴近主标题
  - 装饰密度随情绪调节：安静内省取下限（3 个、约 8%），产品教程发布取上限（5–6 个、约 15%）
must_preserve:
  - 研究报告气质：克制、理性、安静、思想感，像顶级研究机构发布的视觉报告
  - 单一主标题作为绝对视觉中心；小标签至多一个；不加页码、日期、品牌署名、无意义英文
  - 纯色平涂背景，无渐变；插画为手绘线稿，低饱和
  - 装饰系统的大小对比与呼应（大色块 + 小圆点），不是均匀撒点
  - 主标题完整、汉字正确、清晰可读
avoid_when_applying_to_cover:
  - 直接画主题物品：AI 不画机器人，网页不画普通电脑，知识不画书堆
  - 营销海报感、科技发布会感、商业模板感
  - 赛博朋克、霓虹、科技蓝光、3D 效果、渐变
  - 密集信息图、大量文字（简洁图标 + 虚线关系图可以）
  - 装饰色块均匀排列、像 UI 按钮、大量散点
  - Anthropic / Claude 的 logo 或品牌字样入画
```

## 风格意图

Anthropic Research、AI 实验室报告、设计研究手册的视觉语言：纯色底 + 衬线大标题（带强调色句点）+ 大型有机色块承载的抽象隐喻线稿 + 大小呼应的装饰色块系统 + 大量留白。像一家顶级研究机构发布的一页视觉报告，安静但有编辑设计的细节趣味。该风格只负责视觉语言；平台适配、长文提炼和通用封面约束由 `xenho-cover` 工作流负责。

## 隐喻转译示例

- AI 主题：不画机器人 → 人类轮廓 + 智能节点 + 思考路径
- 网页主题：不画普通电脑 → 数字空间结构、网页模块像建筑一样生成
- 知识主题：不画书堆 → 信息节点汇聚成知识结构
- 产品 / 工具 / 方法论主题：可用简洁图标卡片 + 虚线连接表达输入输出或流程（配等宽小注释），保持稀疏线稿感
- 参考语汇（见 `refs/`）：墨线笔记本里的键孔、苹果与书、节点连线网络、手托住网络、双云叠合、执笔的手

## 适用

- AI、技术、方法论、知识管理、产品思考、研究类内容
- 需要「克制、理性、有思想感」气质的公众号头图、X 封面、文章封面
- 抽象概念的隐喻转译；产品与工具的轻量流程表达

## 避免

- 需要强视觉冲击、大字报式传播力的内容（此风格偏安静）
- 人物肖像、真实场景还原类需求
- 需要多信息层级的教程长图
