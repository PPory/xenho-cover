# Notion 手绘信息图

```yaml
id: notion-doodle
name: Notion 手绘信息图
input_modes: [text]
subjects: [concept, person, scene, process]
outputs: [cover, poster, infographic]
default_ratio: "2.35:1"
required_fields: [主题词, 画幅比例, 语言, 用途]
optional_fields: [副标题, 核心表达, 补充背景, 情绪倾向, 不想出现的元素]
source: styles/notion-doodle/STYLE.md
color_schemes:
  - {id: A, name: 纸白, bg: "#FFFFFF", text: "#191919", default: true}
  - {id: B, name: 暖纸, bg: "#F7F6F3", text: "#191919"}
accent_colors: ["#0075de", "#1686e9", "#f97a6a", "#fd8575", "#ae6dee", "#ff8a32", "#ffd075", "#2b9d9a"]
layout_variants:
  - {id: A, name: 场景插画型, for: 观点文、理念、生活方式}
  - {id: B, name: 流程图型, for: 教程、步骤、操作指南}
  - {id: C, name: 要点归纳型, for: 干货总结、清单}
  - {id: D, name: 对比选择型, for: A vs B、优缺点、前后对比}
  - {id: E, name: 时间线型, for: 历程、发展、计划}
style_anchors:
  - 纸白底 + 纯黑手绘线稿，马克笔质感：粗细不均、笔触松弛、略带抖动，不追求工整
  - 局部黑色填充压实画面（人物头发、物品局部、图标块）
  - 点缀色至多 1–2 种，从八色色板选，小面积平涂（图标局部、下划线、小色块）
  - 按内容从五种构图型（场景 / 流程 / 要点 / 对比 / 时间线）中选一种
  - 装饰元素库点缀留白：星星、星球、火箭、纸飞机、小植物、咖啡杯、书本、铅笔、云朵、箭头、对话气泡、小旗帜、打勾、爱心、灯泡、齿轮，取 2–4 个
  - 文字用手写感字体融入画面（写在物品、气泡、便签、旗帜上）
cover_shape_adaptation:
  - 封面必须有主标题层：粗黑手绘马克笔字或简洁黑体，落在清晰留白区，也可写进大对话气泡或横幅旗帜里
  - 构图型按内容选：观点文 → 场景插画型；教程 → 流程图型；干货清单 → 要点归纳型；对比 → 对比型；历程 → 时间线型
  - 横版（2.35:1 / 5:2）：标题居左或居上，信息图主体占其余空间
  - 竖版（3:4）：标题在上，主体纵向展开
  - 封面场景下信息密度取低：流程 3–4 步、要点 3 个，关键词极短
  - 原标题含具体数量（「5 种方法」「7 个技巧」）而封面呈现的要点数与之不符时，A 层标题必须去掉数字或改写到与画面一致——图文数量不符是硬伤
must_preserve:
  - 松弛手绘感：像随手画在纸上的笔记，不精确、不矢量、不工整
  - 黑白是主体，颜色只是点缀；黑色填充有节制地压实画面
  - 大量留白和呼吸感；文字极简
  - 只使用用户提供的内容，不能额外添加信息
  - 主标题完整、汉字正确、清晰可读
avoid_when_applying_to_cover:
  - 彩色渐变、复杂配色、超过 2 种点缀色
  - 粗黑边框、生硬直线分隔（分隔用手绘虚线或波浪线）
  - 3D 效果、阴影、立体感、矢量工整感
  - 密集文字堆砌、要点超过 5 个
  - 装饰元素过多（超过 4 个）或喧宾夺主
  - Notion 的 logo 或品牌字样入画
```

## 风格意图

Notion 官方插画风格（Roman Muradov 一系）：极简、手势感的黑白墨线，像聪明人随手画在纸上的思考笔记——松弛、俏皮、有智性幽默感，受 Saul Steinberg 概念插画影响。适合把内容转化为轻松易读的信息图式封面。该风格只负责视觉语言与构图型；平台适配、长文提炼和通用封面约束由 `xenho-cover` 工作流负责。

## 与 anthropic-research 的分工

- `anthropic-research`：纯色底、编辑排版、单一隐喻，气质是「研究报告」——安静、克制、思想感
- `notion-doodle`：纸白底、手绘信息图、内容结构可视化，气质是「聪明笔记」——松弛、亲和、易读传播

内容偏观点与氛围 → 前者；内容偏干货、步骤、清单、对比 → 后者。

## 适用

- 教程、操作指南、干货总结、清单、方法论拆解
- 对比评测、发展历程、计划路线图
- 需要亲和松弛气质、降低阅读门槛的知识类内容

## 避免

- 需要高级感、庄重感的场合（用 anthropic-research）
- 情绪浓度高的叙事文（信息图气质会消解情绪）
- 内容点超过 6 个的长清单（画不下，需先精简）
