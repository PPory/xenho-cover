# 黑白字体样张

```yaml
id: bw-type-specimen
name: 黑白字体样张
input_modes: [text]
subjects: [concept, title]
outputs: [cover, poster]
default_ratio: "3:4"
required_fields: [主题词, 画幅比例, 语言, 用途]
optional_fields: [副标题, 核心表达, 补充背景, 情绪倾向, 不想出现的元素]
source: styles/bw-type-specimen/STYLE.md
color_schemes:
  - {id: A, name: 墨白, bg_light: "#F0F0EE", bg_dark: "#111111", default: true}
style_anchors:
  - 纯黑白双色画面：一条大弧线（巨圆的边缘）把画面切成黑白两大区，形成正负空间
  - 巨型衬线字是唯一图形：标题字被放大到充满画面，可出血裁切、彼此叠压、错落分行
  - 跨区反色：字跨越黑白分界时逐区反色（黑区里白字、白区里黑字），字与背景互相穿透
  - 极端粗细对比的衬线字体（Bodoni/Didot 质感；中文用极端粗细对比的宋体）
  - 小字文本块作专业注脚：右上小标题、右下说明段、左下样张行，像字体规格页
  - 全画面只有字与弧线分区，没有任何插画和装饰图形
cover_shape_adaptation:
  - 主标题拆成 2–3 组巨字错落排布：字可出血、可叠压边角，但每个汉字笔画内部完整、不镂空不拆解
  - 跨区反色是本风格的机关：让标题核心字骑在黑白分界弧线上做反色，视觉焦点自然落位
  - 副标题作为右侧小字文本块（衬线小字，右对齐或两端对齐）
  - 可选：左下角放一行「样张」小字（如数字 0–9 或标题用字的小号重复），增强字体规格页气质
  - 竖版（3:4 / 9:16）：原生比例；横版（2.35:1 / 5:2）：弧线改为纵向切分左右两区，巨字横向错落
must_preserve:
  - 纯黑白，无第三色、无灰阶过渡（除字体本身的锐利边缘）
  - 巨字的尺度感——字必须大到有压迫力，出血裁切是尺度的证明
  - 汉字笔画内部完整，裁切只发生在画框边缘，不发生在字内部
  - 正负空间的图底游戏清晰可读
  - 主标题整体仍可辨认拼读
avoid_when_applying_to_cover:
  - 在字内部开洞、拆解笔画（裁切只能来自画框出血或字与字叠压边缘）
  - 出现黑白以外的颜色
  - 加入插画、图形、装饰元素——这是纯排版风格
  - 巨字太小、变成普通排版海报
  - 叠压过度导致标题无法拼读
  - 把 BODONI 字样或真实字体厂商名画进图
```

## 风格意图

经典字体样张海报（type specimen poster）的语言：把字体本身当作唯一的图形素材，巨型衬线字在黑白正负空间里出血、叠压、跨区反色，配小字规格注脚。气质古典而先锋——像字体厂商的规格页被放大成美术馆海报。中文语境用极端粗细对比的现代宋体承接 Bodoni 的角色。该风格只负责视觉语言；平台适配、长文提炼和通用封面约束由 `xenho-cover` 工作流负责。

## 适用

- 标题本身是主角的文章：宣言、命名、概念提出、金句文
- 文字、写作、语言、出版、设计类元话题
- 需要古典高级感 + 现代张力的品牌向内容
- 黑白摄影集、作品集发布

## 避免

- 需要具象画面或色彩情绪的内容
- 标题超过 6 字且无法压缩（巨字装不下）
- 轻松活泼的大众话题（气质太庄重）
