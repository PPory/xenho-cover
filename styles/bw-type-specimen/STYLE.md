# 黑白字体样张

## 视觉风格原子

创作一张黑白字体样张海报（type specimen poster 语言）。风格核心：字体本身是唯一的图形素材——巨型衬线字充满画面，在被一条大弧线切开的黑白正负空间里出血、叠压、跨区反色；小字文本块像字体规格页的注脚。气质古典而先锋，像字体厂商的规格页被放大成美术馆海报。

## 色彩系统

纯黑白双色，无第三色、无灰阶：

- 纸白：`#F0F0EE`
- 墨黑：`#111111`

## 正负空间结构（核心）

- 一条**大弧线**（一个巨大圆形的边缘，圆心在画面外）把画面切成黑白两大区——一侧纸白、一侧墨黑，弧线本身不描边，由两区颜色相接形成。
- 黑白两区的面积不均等（约 4:6 或 3:7），弧线的曲率舒缓优雅。
- 这条分界弧线是画面唯一的「图形」，其余全部由文字构成。

## 巨字系统（核心）

- 主标题拆成 2–3 组巨型衬线字，错落分行排布，字号大到有压迫力——最大的字高约占画面高度 25–35%。
- 字体：极端粗细对比的衬线体——英文用 Bodoni / Didot 质感，中文用横细竖粗、对比极端的现代宋体（标宋 / 报宋的展示级形态）。
- **跨区反色**：巨字骑在黑白分界弧线上时逐区反色——落在黑区的部分是白字，落在白区的部分是黑字，字与背景互相穿透。这是本风格的机关。
- 巨字可以出血（撞出画框边缘被裁掉一部分）、可以彼此叠压边角，但**每个汉字笔画内部完整**——裁切只发生在画框边缘和字与字的叠压边缘，绝不在字内部开洞或拆解笔画。
- 叠压与出血后，标题整体仍可按顺序拼读。

## 图文关系

- 右上角：完整标题的小号衬线版本（像刊名），下方一行更小的副标题。
- 右下或左下：一段小字说明文本块（衬线小字，两端对齐，3–6 行）——内容用文章的一句话语境，像字体规格页的介绍段。
- 可选：左下角一行「样张行」——标题用字的小号重复或数字 0–9 序列，增强规格页气质。
- 汉字必须正确、完整、清晰可读；巨字的反色与叠压不得造成错字感。
- 文字总量：巨字标题 + 小号完整标题 + 副标题 + 一段说明 +（可选）样张行。

## 风格特有禁用项

- 不要在字内部开洞、镂空或拆解笔画。
- 不要出现黑白以外的任何颜色。
- 不要加入插画、图形、纹理、装饰元素——这是纯排版风格。
- 不要让巨字缩小成普通排版（尺度感是风格的命）。
- 不要叠压过度导致标题无法拼读。
- 不要把 BODONI 字样或任何真实字体厂商名画进图。
