style_anchors:
  - 一个概念物统治整张画面：它是隐喻的唯一载体，画面里不允许出现第二个视觉焦点
  - 尺度对比是核心修辞：一个小到看不清脸的人物剪影，站在 / 走向 / 被包在一个巨大的概念物旁边或内部，两者体量差至少 8 倍

  - 完整的电影海报排版层级（本风格的身份证）：顶部一行极小的 presents 引导行 → 主标题 → 底部密集 credits block
  - 底部 credits block 是密集的多列极小字，居中对齐、字号小到近乎纹理，是版式的压舱物
  - 有机自然元素做唯一点缀：一枝伸进画面的树枝 / 花枝 / 一片云，从画框边缘探入，绝不居中

  - 标题允许与概念物叠压：字压在物的剪影上（反色）或物的边缘越过字的外围，但笔画本身完整

  - 横版（2.35:1 / 5:2）：概念物移到画面右侧三分之一并向上出血，标题与 credits 竖向堆叠在左侧，人物剪影落在物的基座处

  - 单一饱和底色的纯度：平涂、无渐变、无光效、无噪点滤镜
  - 剪影 / 负形的干净轮廓，形状本身要能被一眼认出

## 风格意图

华语与国际艺术电影海报一路的平面语言（参考《太阳照常升起》《嘉年华》《黄金时代》一类的主视觉）：一整面饱和实色底上立着一个巨大的概念物，一个小到看不清脸的人站在它脚下或被包在它的负形里，顶部一行引导小字、中间一组标题、底部一块密集到近乎纹理的 credits，把画面钉成一件正式发行的海报。气质是隆重、克制、有文学分量的——靠尺度和色彩说话，不靠细节和光影。该风格只负责视觉语言；平台适配、长文提炼和通用封面约束由 `xenho-cover` 工作流负责。

## 与库内其他风格的分工

- `cinematic-photo-editorial`（电影感摄影排版）：满幅**实拍摄影** + 单色调分级 + 巨字长在景深里，本质是「一张照片」。本风格相反——纯色平面 + 剪影概念物，本质是「一张海报」。需要真实场景氛围用前者，需要一个隐喻物立在那里用本风格。
- `bw-type-specimen`：纯排版、无图形，靠字的正负空间；本风格的主角是概念物，字是配角。
- `polish-grain-collage`：颗粒拼贴、字符散落、先锋实验；本风格版式规整隆重，是发行物不是实验海报。
- `business-magazine-front-page`：同样有强隐喻物，但那是商业判断 + 编辑栏；本风格是文学气质 + 电影海报层级，不下判断、只给意象。

## 适用

- 有单一强意象、适合被立成一个物的主题：概念提出、命名、时代情绪、文学与艺术话题
- 需要隆重感和文学分量的长文封面
- 人在结构 / 时代 / 系统面前很小 —— 这类母题是本风格的正命题
- 小红书竖版（原生 2:3 / 3:4，海报感强）、公众号头图

## 避免

- 教程干货、清单、步骤（用 notion-doodle）
- 需要真实场景与氛围质感的内容（用 cinematic-photo-editorial）
- 找不到可以立成一个物的核心意象的题目——本风格靠概念物吃饭，物立不住整张就垮
- 轻快、亲和、日常的话题（气质太隆重）
