# 概念物电影海报

## 视觉风格原子

创作一张艺术电影海报风格的平面主视觉。风格核心：一整面饱和实色底上立着一个巨大的概念物（纯色剪影或负形挖出），一个小到看不清脸的人物剪影站在它脚下或被包在它的内部，两者的体量差就是全部的修辞；顶部一行极小的引导字、中间一组标题、底部一块密集到近乎纹理的 credits，把画面钉成一件正式发行的海报。气质隆重、克制、有文学分量——靠尺度和色彩说话，不靠细节和光影。这是平面海报，不是插画，也不是照片。

## 色彩系统

大面积单一饱和实色底 + 一种主体色 + 一种文字色。平涂、无渐变、无光效、无噪点滤镜。按内容气质选一套，一次只用一套：

- **方案 A 正红黑影**（默认，灼烈 / 记忆 / 时代热度）：底 `#C8102E`，主体与剪影 `#0E0E0E`，文字 `#F2EFE9`
- **方案 B 靛蓝金箔**（沉静 / 书写 / 历史分量）：底 `#17233F`，主体 `#C9A227` 且带细密金箔颗粒质感，文字 `#F2EFE9`
- **方案 C 天蓝朱红**（疏离 / 荒诞 / 权力）：底 `#4A7FB5`，主体 `#C1362F`，基座或地面 `#E07B39`，文字 `#F2EFE9`。这是唯一的三色撞色方案，三色必须硬碰硬、互不调和。

底色是情绪本身，不许降饱和、不许调灰、不许做旧、不许加渐变或纹理噪点。方案 B 允许在底色上加极细的等距竖向暗纹（像丝绢或旧纸的纹理），但明度差极小，远看仍是纯色。

## 概念物系统（核心）

- **只有一个概念物**，它统治整张画面，是隐喻的唯一载体。画面里绝不允许出现第二个视觉焦点。
- 概念物从内容的核心张力提炼，必须是**具体可辨的物**（一支笔、一座塔、一扇门、一双鞋、一只手），不是抽象几何或光效。禁止直译主题词。
- 画法是**纯色剪影或负形挖出**：轮廓干净、内部平涂、无高光、无阴影、无体积、无材质渲染。形状说话，材质不说话。方案 B 例外——主体可填充细密金箔颗粒，但仍是平面填充，不做立体。
- 概念物必须大：至少占画面高度的 60%，且至少有一侧出血到画框外。它应该顶天立地，让人第一眼只看见它。
- **负形用法**（进阶）：可以在概念物内部挖出一个人形的负形，让底色从人形处透出来——人不是画上去的，是物里缺掉的那一块。

## 尺度对比（本风格的命门）

- 画面里必须有一个**人物剪影**，纯色、无面部细节、无服装细节，只有轮廓和姿态。
- 人与概念物的体量差**至少 8 倍**：人小到需要找一下才看见，物大到无法忽略。
- 人的位置：站在物的脚下 / 基座上 / 正走向物 / 被包在物的负形里。姿态要有明确的方向性（仰头、走近、背对），不要随意站着。
- 人是给尺度的，不是当主角。人一画大、一画出五官，这个风格立刻垮掉。

## 自然点缀

- 全画面只允许一处自然元素：一枝树枝、花枝或一片云，从画框的某个角或边缘**探入**画面，占面积很小（不超过 12%）。
- 它必须从边缘进入，绝不居中、绝不完整——不画一整棵树、不画一整丛花。
- 颜色与主体同色（剪影）或与主体色同族，不引入第四种颜色。
- 它的作用是打破纯色底的空旷、给一点呼吸和季节感，不承担隐喻。

## 排版层级（本风格的身份证）

三段式，缺一段就退化成普通插画海报：

1. **顶部引导行**：一行极小的全大写宽字距文字，居中或左对齐，落在画面上缘。字号约为主标题的十五分之一。
2. **主标题**：全画面第二大的元素（仅次于概念物）。中文用极端粗细对比的现代宋体或厚重黑体，可横排也可**竖排**（竖排更贴华语艺术电影海报的原生语法）；西文用高对比衬线巨字。标题允许与概念物叠压——字压在物的剪影上并反色，或物的边缘越过字的外围——但笔画本身必须完整。
3. **底部 credits block**：一块密集的多列极小字，居中对齐，字号小到接近纹理，行距极紧。这是版式的压舱物，必须有。它的每一个字都必须在提示词里被指定，绝不允许留空槽让模型自行编造演职员名单或真实人名。

副标题（如有）作为一行小字紧贴主标题下方，字号约为主标题的六分之一。

## 图文关系

- 中西文混排：中文标题配英文小字，或英文巨字配中文小注。两种语言的字重和字号要有明确层级，不平起平坐。
- 汉字必须正确、完整、清晰可读；与概念物叠压时只改变颜色（反色），不改变字形，也不允许物的轮廓切断任何一笔。
- 文字总量：顶部引导行 + 主标题 + （可选）一行副标题 + 底部 credits block。

## 风格特有禁用项

- 不要把概念物做成写实渲染、3D、加高光投影或材质贴图——本风格是平面剪影。
- 不要把人物画大、画出五官、画成人物海报。
- 不要缺少底部 credits block，也不要把它写成可辨读的假演职员表或真实人名。
- 不要出现真实电影名、片方名、影展名、评奖标识（金狮、金棕榈、威尼斯、戛纳等）及其近似图形。
- 不要给底色加渐变、做旧、纹理噪点，或换成灰调。
- 不要在画面里放第二个概念物或第二个视觉焦点。
- 不要把自然点缀画成完整的树或花丛——只能是从边缘探入的一枝。
- 不要写实照片、摄影质感、景深虚化（那是 `cinematic-photo-editorial` 的领域）。
