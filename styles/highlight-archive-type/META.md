# 荧光档案打字机

```yaml
id: highlight-archive-type
name: 荧光档案打字机
input_modes: [text]
subjects: [concept, title, object]
outputs: [cover, poster]
default_ratio: "2.35:1"
required_fields: [主题词, 画幅比例, 语言, 用途]
optional_fields: [副标题, 核心表达, 补充背景, 情绪倾向, 不想出现的元素]
source: styles/highlight-archive-type/STYLE.md
color_schemes:
  - {id: A, name: 冷灰纸绿, paper: "#E8E7E2", paper_light: "#F1F0EB", paper_edge: "#D6D5CF", ink: "#10140C", accent: "#9FE320", default: true}
style_anchors:
  - 冷调浅灰纸底铺满全画面（#E8E7E2），带真实纸纤维颗粒、轻微暗角与折痕感，像一页归档文书被平拍下来；纸是中性偏冷的灰白，不是暖米黄、不是牛皮纸
  - 标题是黑色打字机质感的粗字（等宽感、方头 slab 衬线、笔画粗细近乎均一），横向压在荧光绿高亮条上
  - 荧光绿高亮条（#9FE320）只出现在文字底下，像宽头记号笔一笔拉过——**主标题的每一行都必须被整行高亮，从行首第一个字盖到行末最后一个字，不做选择性划词**
  - 每条高亮的长度由该行文字的实际宽度决定，因此多行之间自然不等长、右端错开；但每一条本身是边缘干净锐利的实心矩形，不做撕边、不做参差毛边
  - 高亮条高度约为字腔高的 75–90%，压在字腰位置：字的升部与降部略探出条外，条几乎包住整行但不完全裹死
  - 右下角一件与主题相关的物件做半调网点（halftone）处理，黑白剪影感，边缘网点变稀、融进纸底，没有硬边框和投影
  - 全画面只有三色：纸底 / 墨黑 / 荧光绿。无第四色、无渐变、无光效
cover_shape_adaptation:
  - 主标题拆成 1–2 行左对齐，**每一行都独占一条整行高亮条**，全部标题字都坐在绿色上；这是本风格的固定形态，不做「只划关键词」的变体
  - 态度的表达不靠「划哪几个字」，而靠标题本身的断行取舍：哪句话被提上来当主标题、断在哪里，就是这张封面的判断
  - 中文用等宽感黑体或仿宋承接打字机气质：方头、字重偏粗、字距略放宽、字形完整精确；拉丁字母/数字用打字机式方头衬线，与中文同字重同基线
  - 副标题作为标题下方一行小字（字重更轻、字距更宽），其中最关键的 2–4 个字带一小截绿高亮，形成主 / 次两级标记
  - 半调物件占画面 18–30%，落右下角或右侧，可轻微压出画框边缘，不得压住任何文字
  - 竖版（3:4 / 9:16）：标题多行堆叠居中偏上，半调物件落底部；横版（2.35:1 / 5:2）：标题左侧两行，半调物件右侧下方，中间留呼吸
must_preserve:
  - 高亮条的「标记」语义：它是记号笔拉过的动作痕迹，不是背景块、不是分割条、不是装饰几何
  - 条严格按行文字宽度裁切，多行之间不等长、右端错开；升部降部略探出条外——这是「一笔拉过」而非「排版填色」的证据
  - 主标题整行高亮，全部标题字坐在绿色上
  - 纸底是中性偏冷的浅灰白，有颗粒、暗角与轻微不匀（档案气质全靠这一层，纸干净了或纸发暖发黄，风格就死了）
  - 半调物件必须看得出网点结构，是印刷复制品的感觉，不是灰度照片
  - 荧光绿在纸底上的高饱和反差（唯一的强色，且只出现在文字底下）
  - 主标题完整、汉字正确、清晰可读
avoid_when_applying_to_cover:
  - 高亮条脱离文字变成纯装饰色块、背景大面积铺绿、或多条绿条被拉成等长对齐的矩形组
  - 主标题只有部分字被高亮、或整行标题一处绿都没有（本风格的固定形态是每行整行高亮）
  - 纸底做成暖米黄、牛皮纸、做旧发黄的色调（必须是中性偏冷的浅灰白）
  - 绿色用在文字本身（绿色字、绿描边、绿投影）——绿只在字的**底下**
  - 半调物件改成彩色照片、写实照片或矢量插画
  - 字效损害汉字结构：镂空、拉伸压扁、笔画断裂、字与字叠压遮住笔画
  - 纸底做成塑料质感 / 纯净无颗粒 / 白色打光背景
  - 出现第四种颜色、渐变、光效、3D、投影特效
  - 把 Registrar、Gracetype 或任何真实字体产品名、字体厂商名、logo、字重列表、字符集样张画进图
```

## 风格意图

字体宣传图 / 归档文书的语言转译：一页带颗粒的浅米灰纸上，黑色打字机粗字被荧光记号笔划出重点，右下角一件半调网点化的物件像剪报里贴上去的插图。核心机关是**「高亮 = 标记」**——荧光笔划过哪几个字，就是画面在替读者做判断，被划中的字是态度，没被划中的字是背景。气质轻快、文书感、有一点玩笑式的严肃。该风格只负责视觉语言；平台适配、长文提炼和通用封面约束由 `xenho-cover` 工作流负责。

## 与库内其他风格的分工

- `anthropic-research`：安静编辑风，隐喻靠插画，气质克制
- `swiss-grid-scrawl`：网格与手写对撞，气质冷感专业，重
- `bw-type-specimen`：纯黑白巨字样张，气质庄重先锋，重
- `highlight-archive-type`：补的是「轻量文书感 + 一抹荧光」位——纸面轻、字量少、一处强色，比上面几个都轻快，适合带自嘲、带态度、带一点随手感的表达

## 适用

- 有明确态度或判断的观点文（因为高亮条本身就是在划重点）
- 个人叙述、行业观察、吐槽与自嘲兼具的内容
- 与文档、记录、归档、写作、字体相关的元话题
- 标题短（中文 4–10 字）且有一两个关键词值得被划出来的选题

## 避免

- 需要宏大、庄重、高级感的品牌向内容（这个风格太轻）
- 没有明确态度的中性资讯（高亮条无处可划，机关空转）
- 信息点多的教程干货（用 notion-doodle）
- 需要彩色照片或复杂画面的内容
