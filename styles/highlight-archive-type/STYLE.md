# 荧光档案打字机

## 视觉风格原子

创作一张「荧光档案打字机」风格的封面。画面是一页浅米灰的带颗粒纸张平拍：黑色打字机质感的粗字横排其上，几条荧光绿的高亮条像记号笔一笔划过，把标题里最关键的字划了出来；右下角一件与主题相关的物件被做成半调网点的黑白剪影，边缘融进纸底。核心机关：**高亮即标记**——荧光笔划中的字是态度，没被划中的字是背景，划与不划本身就是叙事。气质轻快、文书感、带一点玩笑式的严肃。

## 色彩系统

全画面三色，无第四色、无渐变、无光效：

- 纸底冷调浅灰：`#E8E7E2`——铺满整幅；中心可提亮至 `#F1F0EB`，四角自然压暗至 `#D6D5CF`，最亮的纸纹高光约 `#F7F6F2`。这是**中性偏冷的灰白纸**，不是暖米黄、不是牛皮纸、不做做旧发黄
- 墨黑：`#10140C`——标题、小字、半调网点，略带一点冷绿的深黑，不是纯 `#000000`
- 荧光绿：`#9FE320`——唯一强色，平涂无渐变，**只出现在文字底下的高亮条上**

## 纸底与质感

- 纸底不是纯色：有可见的纸纤维颗粒、细微的斑点与色斑、轻微的横向纹理，像扫描件而非数字底色。
- 四角与边缘有柔和的暗角（vignette），中心略亮——这是「一页纸被平拍」的物理证据。
- 允许极轻的折痕或纸边阴影暗示，但不要做成撕纸、卷边、做旧脏污。
- 纸面干净到没有颗粒，这个风格就不成立。

## 核心机关：荧光高亮条

这是本风格唯一不可替换的部分，按以下规则画：

- 高亮条**只出现在文字底下**，永远与某一行字绑定。它不是背景块、不是分割条、不是装饰几何图形。
- **主标题的每一行都必须被整行高亮**：从该行第一个字的左侧一点点，一直盖到最后一个字的右侧一点点，全部标题字都坐在绿色上。这是本风格的固定形态——不做「只划关键词、其余留白」的变体。
- 条的长度由该行文字的实际宽度决定，因此多行之间自然不等长、右端错开。但**每一条本身是边缘干净锐利的实心矩形**（像宽头记号笔一笔平稳拉过），不做撕边、不做毛边参差、不做多次涂抹的重叠深浅；同时也绝不把多条拉成等长对齐的规整矩形组。
- 条的高度约为字腔高度的 75–90%，压在字腰位置：字的升部（汉字上部笔画、拉丁字母的字高）和降部略探出条外，条几乎包住整行但不完全裹死。
- 条是平涂纯色 `#9FE320`，无羽化、无渐变、无透明叠色。
- 文字压在条上方，黑字直接盖住绿色，不加描边、不反白、不投影。
- **态度由断行承担，不由「划哪几个字」承担**：既然每行都全高亮，这张封面的判断就体现在——哪句话被提上来当主标题、从哪里断行。选句和断行就是论点。
- 副标题小字里可以有一小截更短更矮的绿高亮，标记 2–4 个关键字，形成主 / 次两级标记，让「划重点」看起来是一贯的动作而不是一次装饰。

## 字体与图文关系

- 主标题是打字机质感的粗字：等宽感、方头 slab 衬线、笔画粗细近乎均一、字距略放宽、字腔开阔。
- 中文用等宽感黑体或仿宋承接这个气质（方头、字重偏粗、结构方正），**字形必须完整精确**——打字机质感只体现在字重、字距、方头收笔上，绝不能靠镂空、断笔、压扁、错位来「做旧」。
- 拉丁字母与数字用打字机式方头衬线，与中文同字重、同基线、同字号级别，混排时不喧宾夺主。
- 标题左对齐，1–2 行；行距紧凑（约 0.9–1.1 倍字高），让两行读起来是一句话。
- 副标题在标题下方，同族字体的更轻字重、更小字号、更宽字距，一行为限。
- 除主标题与副标题外，画面不出现任何其他可读文字。

## 半调物件

- 右下角（或右侧）放一件与主题直接相关的**具体物件**，做半调网点（halftone）处理：黑色圆点疏密成像、点阵可见、像老报纸印刷或复印件。
- 物件是剪影感的，无背景、无边框、无投影，边缘的网点逐渐变稀，自然融进纸底——像从旧印刷品上剪下来贴上去的。
- 物件占画面 18–30%，可轻微压出画框边缘制造裁切感，但不得压住任何文字。
- 只放一件物件，不做物件组合、不做拼贴堆叠。

## 风格特有禁用项

- 高亮条脱离文字变成装饰色块、背景大面积铺绿、或多条绿条被拉成等长对齐的整齐图形。
- 主标题只有部分字被高亮，或整行标题一处绿都没有。
- 纸底做成暖米黄、牛皮纸或做旧发黄的色调。
- 绿色用在文字本身（绿色字、绿描边、绿投影、绿色小图标）——绿只在字的底下。
- 半调物件改成彩色照片、写实照片、矢量插画或 3D 渲染。
- 任何损害汉字结构的字效：镂空、拉伸压扁、笔画断裂、字与字叠压遮挡笔画。
- 纸底做成塑料质感、纯净无颗粒的平色，或白色影棚打光背景。
- 出现第四种颜色、渐变、光效、3D、投影特效、噪点滤镜以外的后期特效。
- 把 Registrar、Gracetype 或任何真实字体产品名、字体厂商名、品牌 logo 画进图；也不要出现字重列表、字符集样张、「A Typewriter Font」之类的字体宣传语——这是封面，不是字体样张。
