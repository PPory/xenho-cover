# 电影感摄影排版

```yaml
id: cinematic-photo-editorial
name: 电影感摄影排版
input_modes: [text]
subjects: [scene, concept, person]
outputs: [cover, poster]
default_ratio: "2.35:1"
required_fields: [主题词, 画幅比例, 语言, 用途]
optional_fields: [副标题, 核心表达, 补充背景, 情绪倾向, 不想出现的元素]
source: styles/cinematic-photo-editorial/STYLE.md
color_schemes:
  - {id: A, name: 深海蓝, shadow: "#010B1F", deep: "#011435", mid: "#004498", light: "#0C94DF", highlight: "#B1E1FA", text: "#FFFFFF", default: true}
  - {id: B, name: 暮金琥珀, shadow: "#1A1206", deep: "#33240C", mid: "#8A5E14", light: "#D79A2B", highlight: "#F3DFAE", text: "#FFFFFF"}
  - {id: C, name: 暗林绿, shadow: "#04120C", deep: "#0A2418", mid: "#16543A", light: "#3E9B6B", highlight: "#C6E9D4", text: "#FFFFFF"}
style_anchors:
  - 满幅电影级实拍摄影打底：一张有景深、有体积光、有细腻颗粒的照片铺满整个画幅，出血到四边，没有边框、没有留白区、没有色块背景
  - 整幅照片压成**单一色调**——全图只有一个色相的深浅层次（阴影近黑、中间调是该色相的饱和主色、高光近白），一次只用一种色调方案，不许两种色相并存
  - 巨型紧缩无衬线标题两行叠排，字距极紧到字与字几乎相触，行距极紧到上下行的字面几乎咬合，字号大到横向接近贴满画幅
  - 标题与照片有真实的前后层次：照片中的前景元素（该场景里本就存在的近景物，如枝叶、栏杆、人影、烟尘、草穗）可以轻微压过字的笔画边缘，制造字被埋进景深里的错觉
  - 上缘两处极小编辑标签：左上角栏目名（同一行内做常规体 + 粗体的双重量对比），右上角期号，字号小到只有标题的十五分之一
  - 底部左下一段 3–4 行小字正文，窄栏左对齐，像影片简介
  - 底部右下一排 2–3 枚**虚构**小徽章（画质 / 分级 / 发行式的小标识），纯装饰，制造「正式发行物」的仪式感
  - 画面中部保留一片视觉安静区（该场景里最平、对比最低的那一块——天空、墙面、雾、空地、路面、水面都可以），是为巨字预留的舞台
  - **题材由文章决定，不由参考图决定**：本风格提供的是构图、排版、调色和层级，不规定拍什么。参考图恰好是水下题材，但水、海、潜水绝不是本风格的必要元素
cover_shape_adaptation:
  - 主标题拆成两行叠排：短行在上、长行在下（或反之），左对齐；短行右侧的空缺由照片本身填补，不补任何图形
  - 副标题作为标题正上方的一行小字引导语（尺寸约为巨字的六分之一），与巨字左边缘严格对齐
  - 摄影主体从**文章自身的视觉隐喻**取材，选一个有空间纵深的真实场景即可；场景类型不限——街道、旷野、室内长廊、楼梯间、车厢、天台、工地、田野、山道、码头、雪原、房间一角都成立。判据只有三条：有前中后景的纵深、有一片可让位给巨字的低对比区、场景本身与文章隐喻相扣
  - 人物可有可无；若出现，只作远景剪影或背影，不要正面特写
  - 一句话语境改写成底部 3 行小字正文，40–50 字以内，写完整可读的中文短句
  - 横版（2.35:1 / 5:2）：原生比例，两行巨字横向铺开占画面中段；方版（1:1）：巨字改 2–3 行、整体上移，底部小字与徽章同排；竖版（3:4 / 9:16）：照片纵向取景，巨字压在下三分之一，上缘标签与底部小字区间距拉大
  - 徽章必须自行虚构：抽象几何标记（圆环内三角、细线方框内横杠、圆角矩形内点阵），不带任何可识别的品牌词、字母缩写或分级代号
must_preserve:
  - 单一色调贯穿全图——包括阴影和高光，都是同一色相的明度变化
  - 电影摄影的真实感：自然景深、体积光、细腻胶片颗粒，不是插画、不是 3D 渲染、不是 AI 干净感
  - 巨字的尺度感与极紧的字距行距——字必须大到有压迫力
  - 文字纯白（#FFFFFF），不带描边、不带阴影、不带渐变
  - 主标题完整、汉字正确、清晰可读
avoid_when_applying_to_cover:
  - 因为参考图是水下题材就默认拍水、海、潜水、游鱼、礁石——题材必须来自文章，与参考图题材雷同属于失败
  - 照片前景遮挡吃掉汉字结构——只允许压住笔画的外侧边缘，不许穿过字心、切断笔画、遮住偏旁，任何遮挡后每个汉字仍须完整可辨
  - 出现第二种色相（单色调里混进另一个颜色即失败），或退化成普通调色滤镜（阴影仍是灰黑、没有色相统一）
  - 使用 Dolby、IMAX、HBO、Netflix、R 级、PG-13 等任何真实商标、真实分级标识或其近似变体
  - 巨字加描边、投影、发光、渐变、镂空、立体挤出
  - 在照片上加半透明黑色蒙版压暗来「让字看清」——层次靠调色分级实现
  - 画面加边框、圆角、胶片齿孔、字幕条、播放器 UI
  - 标题字距松散、行距拉开，退化成普通图片配文字
  - 底部小字堆成整段长文，或多于 4 行
```

## 风格意图

电影海报级的编辑排版：一张单色调的氛围摄影铺满画幅，一组巨大到有压迫力的紧缩无衬线标题浮在景深里，上缘极小的栏目标签和底部的简介小字、虚构徽章把它钉成一件「正式发行物」。情绪是安静、辽阔、克制的高级感——照片负责氛围，巨字负责态度，小字和徽章负责仪式感。该风格只负责视觉语言；平台适配、长文提炼和通用封面约束由 `xenho-cover` 工作流负责。

## 适用

- 有空间感、有氛围的主题：自然、旅行、行业观察、时代情绪
- 需要「大片感」和分量感的深度长文
- 单一强观点的标题党式短句（巨字放得下）
- 微信公众号头图（2.35:1）、视频封面

## 避免

- 需要信息密度的干货教程（用 notion-doodle）
- 没有合适实拍场景可依托的纯抽象概念（用 bw-type-specimen）
- 标题超过 10 个汉字（巨字排不下，会被迫缩小而失去尺度感）

## 与库内其他风格的分工

- `torn-photo-collage`（撕纸摄影拼贴）也用摄影，但那是粗粝的手工拼贴物理感——撕边、错位、纸张层叠，标题小而硬。本风格相反：完整无损的一张电影级摄影，标题巨大，气质是发行级的精致而非亚文化的粗粝。
- `bw-type-specimen`（黑白字体样张）也用巨字，但那是纯排版风格，画面里没有照片。本风格的巨字必须长在照片的景深里。
