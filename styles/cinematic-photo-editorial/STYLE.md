# 电影感摄影排版

## 视觉风格原子

创作一张电影海报级的编辑排版封面。风格核心：一张满幅出血的实拍氛围摄影打底，整幅被压成单一色调；一组巨型紧缩无衬线标题两行叠排浮在照片的景深里，照片的前景元素轻微压过字的笔画边缘制造前后关系；上缘两处极小的编辑标签、底部一段简介小字和一排虚构徽章，把整张图钉成一件正式发行物。气质安静、辽阔、克制，像一部不存在的电影的主视觉。

## 色彩系统

整幅摄影压成**一种**单色调（monochrome grade）：全图只有一个色相，靠明度拉开层次。文字永远是纯白 `#FFFFFF`。按主题选一套，一次只用一套：

- **A 深蓝**（默认，夜色 / 冷冽 / 冷静理性）：阴影 `#010B1F`、暗调 `#011435`、中间调 `#004498`、亮调 `#0C94DF`、高光 `#B1E1FA`
- **B 暮金琥珀**（黄昏 / 收获 / 疲惫与暖意）：阴影 `#1A1206`、暗调 `#33240C`、中间调 `#8A5E14`、亮调 `#D79A2B`、高光 `#F3DFAE`
- **C 暗林绿**（森林 / 潮湿 / 隐秘）：阴影 `#04120C`、暗调 `#0A2418`、中间调 `#16543A`、亮调 `#3E9B6B`、高光 `#C6E9D4`

分级要求：阴影必须压到接近黑但仍带该色相（不是中性灰黑），高光可以推到接近白，中间调是画面的主导面积。这是调色分级，不是在彩色照片上盖一层半透明色膜。

## 影像系统（核心）

- **满幅出血**：照片铺满整个画幅并出血到四边，没有边框、没有留白条、没有背景色块。画面就是照片本身。
- **电影摄影质感**：自然景深（前景虚、中景实、远景化开）、体积光或逆光、细腻的胶片颗粒、真实的大气透视。不要插画感、3D 渲染感、AI 塑料光泽。
- **场景选取（题材来自文章，不来自本文件）**：本风格规定的是拍法，不是拍什么。从文章的视觉隐喻里选一个有空间纵深的真实场景——街道、旷野、长廊、楼梯间、车厢、天台、工地、田野、山道、码头、雪原、房间一角，都同样成立。选场景只看三条：有前中后景的纵深、有一块可以让位给巨字的低对比区、场景本身与文章隐喻相扣。
- **安静区**：画面中段留一片低对比的安静区域——就是该场景里最平、细节最少的那一块（天空、墙面、雾、空地、路面、水面反光都可以）。这是给巨字的舞台，周边可以复杂，中间必须让位。
- **前景剪影环绕**：安静区四周散布同色调的深色剪影元素，**元素必须是该场景里本来就会有的东西**（街道就是路灯与行道树、旷野就是草穗与远山、长廊就是立柱与门框、车厢就是扶手与座椅背），大小不一、疏密有致，制造「被环境包围」的纵深。不要从别的场景里借元素。

## 图文关系

- **巨型标题**：极粗的紧缩无衬线体（中文用笔画粗、字面方、字腔紧的黑体），纯白，两行叠排、左对齐。字距极紧到相邻字几乎相触，行距极紧到上下行字面几乎咬合。字号大到横向接近贴满画幅——尺度感是这个风格的命门。
- **前后层次**：照片的前景剪影可以轻微压过标题的笔画**外侧边缘**，让字看起来被埋在景深里。红线：遮挡不得穿过字心、不得切断或吃掉任何一笔、不得盖住偏旁部首；每个汉字在遮挡后仍须结构完整、一眼可辨。宁可不遮，也不要遮坏字。
- **引导小字**：标题正上方一行小字（约为巨字的六分之一），纯白，与巨字左边缘严格对齐，像片名之上的引言。
- **上缘编辑标签**：左上角一处栏目名，同一行里用常规体 + 粗体做双重量对比；右上角一处期号。两处都极小（约巨字的十五分之一），字距略放开。
- **底部简介小字**：左下角一段 3–4 行的窄栏小字，左对齐，行距紧凑，40–50 字以内，像影片简介。
- **虚构徽章行**：右下角与简介小字同一水平线上，排 2–3 枚极小的抽象几何徽章（圆环内三角、细线方框内两条横杠、圆角矩形内点阵），纯白或白色细线。徽章必须完全虚构、只有几何形，不带任何可识别的品牌词、字母缩写或影视分级代号。
- 汉字必须正确、完整、清晰可读。
- 文字总量：巨型标题（两行）+ 一行引导小字 + 两处上缘标签 + 底部 3–4 行简介 + 徽章行，不再有别的文字。

## 风格特有禁用项

- **不要因为参考图是水下题材就默认拍水**：水、海、潜水、游鱼、礁石、气泡都不是本风格的必要元素。题材必须来自文章；产出与参考图题材雷同，属于把「设计语言」误当成「拍摄内容」的失败。
- 不要出现第二种色相——单色调里混进另一个颜色即失败。
- 不要用半透明黑蒙版压暗照片来「让字看清」，层次靠调色分级和安静区实现。
- 不要给巨字加描边、投影、发光、渐变、镂空、立体挤出。
- 不要让前景元素破坏汉字结构。
- 不要使用 Dolby、IMAX、HBO、Netflix、R 级、PG-13 等任何真实商标、真实分级标识或其近似变体——徽章一律自行虚构。
- 不要加边框、圆角、胶片齿孔、字幕条、播放器 UI、二维码。
- 不要把标题字距行距放松，退化成「一张图片配一行标题」。
- 不要把真实电影名、片方名、摄影师名画进图。
