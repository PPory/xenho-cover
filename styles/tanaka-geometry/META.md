# 田中一光几何

```yaml
id: tanaka-geometry
name: 田中一光几何
input_modes: [text]
subjects: [person, concept, symbol]
outputs: [cover, poster]
default_ratio: "3:4"
required_fields: [主题词, 画幅比例, 语言, 用途]
optional_fields: [副标题, 核心表达, 补充背景, 情绪倾向, 不想出现的元素]
source: styles/tanaka-geometry/STYLE.md
color_schemes:
  - {id: A, name: 灰米五色, bg: "#E9E4D8", palette: ["#1C1C1C", "#D9412B", "#E3B23C", "#2E4C7D", "#F5F1E6"], default: true}
color_lock: 只用这一套配色（即 example-image 里样图的配色），不换色；新配色要先出图给用户确认再加
style_anchors:
  - 只用最基本的几何形——圆、正方形、半圆、四分之一圆、菱形——在隐形方格网上拼出一个可辨认的形象（人物侧脸、手、动物、器物）
  - 五色平涂：全部纯色、无渐变、无阴影、无描边，边缘锐利
  - 现代主义的秩序里带一点人的温度和幽默（一个歪头、一个眨眼、一个错位）
  - 隐喻用几何小元素的排列讲：一排相同的方块、一个变色或转向的块
  - 网格秩序可被感知但不画出网格线
cover_shape_adaptation:
  - 竖版（3:4）：几何形象占上部 60–65%，主标题在下部左对齐网格，粗几何黑体两行
  - 横版（2.35:1 / 5:2 / 16:9）：几何形象放在画面右半，主标题在左半垂直居中，左对齐；形象可以从右边缘出血
  - 副标题一行小号细黑体，对齐主标题左边线
micro_type:
  - {slot: 角落编号, example: "03", rule: 可选，一个小号几何数字，用调色板里的一个颜色}
must_preserve:
  - 纯几何构成与五色平涂的纯粹
  - 形象一眼可辨认，同时每一块都是几何形
  - 主标题完整、汉字正确、清晰可读
avoid_when_applying_to_cover:
  - 渐变、阴影、纹理、立体感
  - 用有机曲线、手绘线条画形象（就变成普通扁平插画了）
  - 颜色超过五种
  - 艺伎、和服等日本符号的直接挪用——借构成方法，不借题材
```

## 风格意图

田中一光《日本舞踊》式的几何构成：把形象拆成最基本的几何色块，在隐形网格上重新拼合。Bauhaus 的秩序 + 东方的克制 + 一点幽默。辨识度极高，适合作为个人视觉标识反复使用。该风格只负责视觉语言；平台适配、长文提炼和通用封面约束由 `xenho-cover` 工作流负责。

## 与库内其他风格的分工

- `swiss-concert-poster`：同为几何，但那是抽象节律、无形象；本风格必须拼出一个可辨认的形象。
- `anthropic-research`：那是手绘线稿 + 有机色块；本风格是硬边几何平涂。

## 适用

- 文化、概念、人与系统、个人成长类观点文
- 需要「有设计感又有温度」、辨识度强的封面

## 避免

- 需要真实场景、摄影质感的内容
- 信息量大的清单教程
