# 撕纸摄影拼贴

```yaml
id: torn-photo-collage
name: 撕纸摄影拼贴
input_modes: [text]
subjects: [scene, person, concept]
outputs: [cover, poster]
default_ratio: "1:1"
required_fields: [主题词, 画幅比例, 语言, 用途]
optional_fields: [副标题, 核心表达, 补充背景, 情绪倾向, 不想出现的元素]
source: styles/torn-photo-collage/STYLE.md
color_schemes:
  - {id: A, name: 灰红牛皮, photo: 黑白灰阶, red: "#92271F", kraft: "#A5805E", paper: "#E8E6E0", ink: "#111111", default: true}
style_anchors:
  - 三层面积均衡：黑白照片 45–55% + 深红色块结构 15–25% + 纸质素材与裸露底纸 20–30%——是拼贴板，不是「一张照片加边饰」
  - 黑白纪实摄影（粗颗粒、高对比）被撕裂、错位、局部翻转后重新拼合
  - 深红（#92271F）是有分量的色块结构（大色块 / 宽色带 + 小撕片呼应），唯一的彩色，丝网印哑光质感，不许缩成细边条
  - 素材层 4–6 处，其中至少两片是有面积的纸块（牛皮纸 #A5805E 大片、旧印刷残页），不只是细胶带条
  - 照片的撕裂缝、接缝错位与翻转制造不安定的动势
  - 小号无衬线文字块嵌在照片空白处，像杂志引文；另有一行极小的角落注记
  - 整体像被翻拍的实体拼贴板——纸的厚度、撕边、胶带反光都真实
cover_shape_adaptation:
  - 主标题：小而硬——无衬线粗体（中文黑体），嵌在照片的空白区或贴在一张纸片上，不做大字海报式排版
  - 黑白摄影主体从文章的视觉隐喻取材（场景、物件、动作的纪实感画面），人物可出现但取局部/背影/剪影感
  - 副标题作为引文式小字块（左对齐、窄栏、2–4 行断行），嵌在画面留白处
  - 深红色块位置避开标题与照片主体焦点，起压秤与情绪作用
  - 方版（1:1）原生；竖版（3:4）：照片纵向撕拼；横版（2.35:1 / 5:2）：照片横向铺、红色块靠一端
  - 角落注记一行极小字（可用拼音或英文短语），像作品档案标注
must_preserve:
  - 摄影的纪实颗粒感（不是插画、不是 AI 干净感）
  - 撕裂与错位的手工拼贴物理感：撕边毛糙、层叠有影
  - 深红作为唯一彩色的克制用法
  - 主标题完整、汉字正确、清晰可读
avoid_when_applying_to_cover:
  - 照片独占画面（超过七成）、红色缩成细边条、素材只剩胶带——三层失衡即失败
  - 照片过度美化、变成干净的数字合成
  - 红色泛滥或出现第二种彩色
  - 撕裂错位破坏标题文字（文字层永远贴在最上、完整无损）
  - 元素堆砌过满，失去大块灰白呼吸区
  - 甜美、治愈、滤镜感
  - 把 Scott Clum 或任何真实摄影师、杂志名画进图
```

## 风格意图

Scott Clum / Ray Gun 一路的垃圾摇滚编辑拼贴：黑白纪实摄影被撕裂重组，深红色块压场，牛皮纸胶带和印刷残片层层贴叠，小字像杂志引文嵌在缝隙里。情绪粗粝、真实、带亚文化的不驯感——是五个风格里唯一以「摄影 + 情绪」为核心的。该风格只负责视觉语言；平台适配、长文提炼和通用封面约束由 `xenho-cover` 工作流负责。

## 适用

- 情绪浓度高的叙事文、个人经历、成长与挣扎
- 城市观察、街头文化、亚文化、音乐话题
- 需要「真实感」而非「设计感」的内容
- 反鸡汤、反精致的观点文

## 避免

- 需要干净高级感的品牌内容（用 anthropic-research 或 bw-type-specimen）
- 轻松教程干货（用 notion-doodle）
- 忌讳灰暗情绪的场合
