# 瑞士网格手写对撞

```yaml
id: swiss-grid-scrawl
name: 瑞士网格手写对撞
input_modes: [text]
subjects: [concept, title, object]
outputs: [cover, poster]
default_ratio: "3:4"
required_fields: [主题词, 画幅比例, 语言, 用途]
optional_fields: [副标题, 核心表达, 补充背景, 情绪倾向, 不想出现的元素]
source: styles/swiss-grid-scrawl/STYLE.md
color_schemes:
  - {id: A, name: 灰白黄, bg: "#E4E4E2", paper: "#F5F5F3", ink: "#161616", accent: "#E9CE0B", default: true}
style_anchors:
  - 双层画面结构：一件白色印刷品（杂志/卡片式的封面平拍，带极轻投影）浮在浅灰桌面上，桌面写满潦草墨水手迹
  - 印刷品层是瑞士平面设计范式：白底、严格网格、黑色粗无衬线标题块、左对齐、紧密行距、克制留白
  - 高亮黄（#E9CE0B）色块 / 卡片是唯一强色，上面是标题关键词的表现性手写涂鸦版本——同一个词的「失控形态」
  - 背景手迹层：细墨线潦草书写、密度高但不构成可读文字，像激动的手写感谢信 / 创作手记；手迹**环绕印刷品四周**（上下左右都有），不是只堆在一侧
  - 手迹必须是「真的在写字」的笔迹：每个词的长度、笔画高低、倾斜角度、墨色深浅、连笔与断笔都不相同，行与行基线不平行、行距不匀，偶有涂改与插入的小字——绝对禁止把同一个波形或同一组笔画重复平铺
  - 秩序 vs 失控的对撞是风格的概念核心：网格越严谨，手写越张扬，画面越成立
  - 全画面四组色：浅灰桌面 / 纸白 / 墨黑 / 高亮黄，无其他颜色
cover_shape_adaptation:
  - 主标题落在印刷品层：黑色粗无衬线（中文用紧排黑体，瑞士式多行断行），左对齐网格排版，汉字完整精确
  - 标题的核心词（1–2 个字/词）在黄色块上重复出现为手写涂鸦形态——印刷体与手写体是同一个词的两种人格
  - 副标题作为印刷品层的小字行（黑色小号无衬线），像杂志副题
  - 背景手迹只是笔迹质感，禁止构成可读文字（规避中文错字风险）——但「不可读」必须来自潦草连笔到认不出，不是来自重复同一个符号
  - 印刷品版面不能只有标题：必须有 3–5 个版面元素按网格摆放（大号期号数字、内页拼贴缩略图、字体样张字列、小字信息块、细分隔线），版面越有内容，瑞士网格的秩序感越立得住
  - 印刷品上的内页拼贴缩略图允许出现小面积彩色（像杂志真实内页），总面积不超过画面 8%，不影响全画面以四组色为主
  - 竖版（3:4 / 9:16）：原生比例，印刷品居中占画面 55–70%，手迹环绕四周；横版（2.35:1 / 5:2）：印刷品偏左但仍完整可见，手迹从右侧延展并绕到印刷品的上下两边，不留纯净空白
must_preserve:
  - 双层结构的物理感：印刷品的实拍质感、极轻投影、纸张边缘
  - 瑞士网格排版的严谨（这是对撞成立的前提）
  - 黄色块上手写涂鸦的表现力：狂放、连笔、飞白，与印刷体形成人格反差
  - 背景手迹密而不乱，环绕印刷品四周留出呼吸；笔迹有真实书写的随机变化，不是重复图案
  - 印刷品版面有足够的内容层次（3–5 个元素），不是一张只印了标题的白纸
  - 主标题完整、汉字正确、清晰可读
avoid_when_applying_to_cover:
  - 背景手迹构成可读文字或真实词句（必须是抽象笔迹）
  - **手迹做成重复平铺的图案**：同一个波形、同一串「mmm / www / eee」样的笔画一路重复到底，行与行长得一模一样——这是本风格最刺眼的假笔迹失败
  - 手迹只堆在画面一侧、其余大片留白，失去「印刷品浮在写满字的桌上」的包围感
  - 印刷品层排版松散、失去瑞士网格的严谨感
  - 印刷品上只有标题和副题、没有其他版面元素，显得空且假
  - 黄色使用超过一处主色块、或改用其他强色
  - 手写涂鸦盖住印刷体主标题
  - 彩色照片、渐变、光效、3D
  - 把 IDPURE 或任何真实杂志刊名、条形码、价格栏画进图
```

## 风格意图

瑞士设计杂志封面场景的当代转译（参考 IDPURE 杂志实拍）：严谨的瑞士网格印刷品浮在写满激动手迹的桌面上，一张高亮黄卡片上是标题关键词的失控手写形态。概念核心是「秩序与失控的对撞」——理性的排版和情绪的笔迹同框，谁也压不住谁。该风格只负责视觉语言；平台适配、长文提炼和通用封面约束由 `xenho-cover` 工作流负责。

## 与库内其他风格的分工

- `anthropic-research`：安静研究报告，隐喻靠插画
- `notion-doodle`：松弛信息图，靠结构可视化
- `polish-grain-collage`：先锋海报，靠字符解构与颗粒冲击
- `swiss-grid-scrawl`：编辑设计感最强，靠排版秩序与手写情绪的张力；适合「理性 vs 感性」母题

## 适用

- 创作、写作、设计、思考过程类内容（手迹 = 创作现场感）
- 理性与情绪有张力的话题：焦虑与克制、计划与失控、专业与热情
- 设计、排版、字体、出版相关的元话题
- 需要「设计杂志级」品味的品牌向内容

## 避免

- 亲和轻松的大众话题（气质偏专业冷感）
- 信息点多的教程干货（用 notion-doodle）
- 需要暖色调、人情味的内容
