# 瑞士网格手写对撞

## 视觉风格原子

创作一张「瑞士网格 × 手写对撞」风格的编辑设计封面。画面是双层结构：一件严谨的瑞士平面设计印刷品平拍在浅灰桌面上，桌面写满激动潦草的墨水手迹，一张高亮黄卡片上是标题关键词的失控手写形态。概念核心：**秩序与失控的对撞**——理性的网格排版和情绪化的笔迹同框，谁也压不住谁。整体像一本瑞士设计杂志的实拍场景，品味冷静专业。

## 色彩系统

主色系四组色，无渐变：

- 桌面浅灰：`#E4E4E2`——背景层，承载手迹
- 纸白：`#F5F5F3`——印刷品的纸面
- 墨黑：`#161616`——印刷体文字与手写笔迹
- 高亮黄：`#E9CE0B`——唯一强色，只出现在一张卡片 / 色块上

**唯一的例外**：印刷品上那块内页拼贴缩略图允许出现小面积彩色（红、蓝、金一类），像真实杂志的内页预览，总面积不超过整幅画面的 8%。除此之外全画面严格四色——彩色只能待在缩略图里，绝不允许溢出到桌面、手迹或标题上。

## 双层画面结构（核心）

**下层：手迹桌面**

- 浅灰桌面写满细墨线潦草手写——像一封激动的手写感谢信或创作手记，连笔、飞白、行距不匀。
- 手迹密度高但**不构成可读文字**：只是抽象笔迹质感，不出现任何真实词句。注意「不可读」的来源必须是**潦草连笔到认不出**，不是「重复同一个符号」。
- **手迹必须像真的在写字（关键，最高频翻车点）**：
  - 每一「词」的长度都不同——有的两三个字母长，有的拖得很长；
  - 笔画的高低起伏不同——有的冒出上行线、有的甩到下行线以下；
  - 倾斜角度逐行变化，行与行的基线**不平行**，行距不匀，有的行往上翘、有的往下坠；
  - 墨色深浅不一，起笔重、收笔飞白，偶尔断墨；
  - 有连成一长串的地方，也有断开成单个短笔画的地方；
  - 允许出现涂改的横杠、插入的小字、写歪了又补一笔的痕迹。
  - **绝对禁止把同一个波形、同一组笔画重复平铺**（例如整片都是「mmm」「www」「eee」样的等高波浪，每行长得一模一样）——这是一眼就能看穿的假笔迹，本风格最刺眼的失败。
- 手迹**环绕印刷品四周**：上、下、左、右都要有，不能只堆在一侧而让其余大片留白；靠近印刷品边缘处留出一圈呼吸空隙。

**上层：瑞士印刷品**

- 一件白色印刷品（杂志封面 / 大卡片）平拍居中，带极轻的真实投影和纸张边缘，占画面 55–70%。
- 印刷品排版是严格的瑞士平面设计范式：白底、网格对齐、黑色粗无衬线标题块、左对齐、紧密行距、克制留白。
- **印刷品上必须有 3–5 个版面元素**（不能只印一个标题，那样又空又假），从下列里选，全部严格按同一套网格摆放：
  - 一个大号期号数字，压在版面右上角；
  - 一块内页拼贴缩略图（几张小图错落叠放），**允许出现小面积彩色**，像真实杂志的内页预览，总面积不超过整幅画面的 8%；
  - 一列字体样张字（同一个词的大小写 / 不同字重成对排列，如 `ARGHS / arghs`），纵向堆叠在版面左下；
  - 一个小字信息块（两三行极小字，做成不可辨读的排版占位质感）；
  - 一条细分隔线或一组细网格线。
- 版面越有内容，瑞士网格的秩序感越立得住，右下角那块黄的手写才越有对撞的力量。

**黄色对撞层**

- 一张高亮黄 `#E9CE0B` 卡片 / 色块叠在印刷品上（微微倾斜或压边），是全画面唯一的强色。
- 黄卡片上是**标题核心词的表现性手写涂鸦形态**：狂放、连笔、重复书写、笔画飞出——和印刷品上的同一个词形成「同词两种人格」的对照。

## 图文关系

- 主标题在印刷品层：黑色粗无衬线，中文用紧排黑体、瑞士式多行断行，左对齐，汉字完整精确、清晰可读。
- 标题核心词（1–2 个字）在黄卡片上以手写涂鸦形态再次出现——这是唯一允许潦草的「真实文字」，且潦草不等于错字，字形骨架仍需正确。
- 副标题作为印刷品上的小字行，黑色小号无衬线，像杂志副题。
- 除主标题、核心词涂鸦、副标题外，画面不出现其他可读文字。

## 风格特有禁用项

- 背景手迹不得构成可读文字或真实词句。
- **手迹不得做成重复平铺的图案**——同一个波形一路重复、每行长得一模一样，是本风格最刺眼的失败。
- 手迹不得只堆在画面一侧，必须环绕印刷品四周。
- 印刷品不得只印一个标题——版面元素少于 3 个就会显得空且假。
- 印刷品排版不得松散——网格越严谨，对撞越成立。
- 彩色不得溢出内页缩略图之外。
- 黄色只出现一处主色块，不得改用其他强色。
- 手写涂鸦不得盖住印刷体主标题。
- 不要彩色照片、渐变、光效、3D。
- 不要把 IDPURE 或任何真实杂志的刊名、条形码、价格栏画进图。
