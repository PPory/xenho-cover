# xenho-cover 风格目录

风格原子存放在仓库级 `styles/` 目录。只有 `META.md` 的 `outputs` 包含 `cover` 或 `poster` 的风格才能进入封面菜单。

不要把风格提示词正文复制进本目录；确定风格后再读该风格的 `META.md` 和 `STYLE.md`。

## 内容 → 风格匹配

- 观点文、氛围叙事、抽象概念、研究感 → `anthropic-research`
- 教程、操作步骤、干货总结、清单、对比、路线图 → `notion-doodle`
- 文化议题、冲突檄文、活动演出、标题即卖点 → `polish-grain-collage`
- 创作过程、理性感性张力、设计出版元话题 → `swiss-grid-scrawl`
- AI 工具、系统、工作流、硬核技术、数码与平台机制 → `cyber-industrial-panel`
- 商业趋势、公司产品分析、投资创业、需要下判断的行业观察 → `business-magazine-front-page`
- 宣言、金句、命名与概念、文字类元话题 → `bw-type-specimen`
- 情绪叙事、个人经历、街头亚文化、反精致 → `torn-photo-collage`
- 第一人称态度、情绪浓度高、漫画感 → `retro-halftone-pop`（主体可以是脸，也可以是物或一组东西）
- 暗色宣言、复古印刷粗粝感、标题即态度 → `dirty-typewriter-specimen`
- 轻快表态、划重点式观点、文书感 → `highlight-archive-type`
- 场景体验、氛围大片、旅行与在场感 → `cinematic-photo-editorial`
- 单一强意象、隆重文学感、「人在结构 / 时代面前很小」→ `film-poster-icon`
- `cinematic-photo-editorial` vs `film-poster-icon`：前者是「一张照片」（实拍摄影 + 单色调分级），后者是「一张海报」（纯色平面 + 概念物剪影）。要真实场景氛围用前者，要一个隐喻物立在那里用后者。
- 多个都沾边时看气质需求：「高级安静」→ anthropic-research；「亲和易读」→ notion-doodle；「先锋冲击」→ polish-grain-collage；「专业冷感 + 情绪张力」→ swiss-grid-scrawl；「冷静未来感」→ cyber-industrial-panel；「媒体权威感」→ business-magazine-front-page；「古典排版张力」→ bw-type-specimen；「粗粝真实感」→ torn-photo-collage；「波普情绪冲击」→ retro-halftone-pop；「复古印刷宣言」→ dirty-typewriter-specimen；「轻快标记感」→ highlight-archive-type；「电影氛围」→ cinematic-photo-editorial

## 平台推荐

- 公众号（2.35:1）：`anthropic-research` 横版左字右图；`notion-doodle` 按内容选构图型；`polish-grain-collage` 字符沿横向对角散落；`swiss-grid-scrawl` 印刷品偏左、手迹右侧延展；`cyber-industrial-panel` 面板横向咬合；`business-magazine-front-page` 原生横版头版式分区；`bw-type-specimen` 弧线纵切左右两区；`torn-photo-collage` 照片横铺、红色块靠一端；`dirty-typewriter-specimen` 左字右图 60/40 咬合；`retro-halftone-pop` 人物特写右置、标题左下；`highlight-archive-type` 横版纸页、标题居左；`cinematic-photo-editorial` 原生宽银幕满幅；`film-poster-icon` 概念物移到右三分之一并向上出血、标题与 credits 竖向堆叠在左
- X（5:2）：`anthropic-research` 非对称排布；`notion-doodle` 场景型或流程型横排；`polish-grain-collage` 横向对角散落；`cyber-industrial-panel` 面板横向咬合；`business-magazine-front-page` 通栏大标题头版；`bw-type-specimen` 巨字横向错落；`cinematic-photo-editorial` 宽银幕满幅；`dirty-typewriter-specimen` 左字右图
- 小红书（3:4）：`polish-grain-collage` 原生竖版海报（冲击力强）；`swiss-grid-scrawl` 原生竖版（设计感强）；`cyber-industrial-panel` 竖版面板堆叠（原生 9:16）；`business-magazine-front-page` 杂志封面式纵向层级；`bw-type-specimen` 原生竖版巨字；`torn-photo-collage` 竖版纵向撕拼；`retro-halftone-pop` 竖版人物特写（情绪冲击强）；`cinematic-photo-editorial` 竖版大片；`film-poster-icon` 原生竖版海报（概念物顶天立地 + 竖排标题，海报感最强）；`highlight-archive-type` 竖版纸页；`dirty-typewriter-specimen` 竖版字号阶梯堆叠；`notion-doodle` 竖版信息图；`anthropic-research` 竖版标题主导（偏安静）

## 风格确认规则

- 用户点名风格：直接用。
- 用户未点名：按「内容 → 风格匹配」推荐至多 3 个候选风格、各给一句贴内容的理由并标注首选，在确认平台的同一条消息里顺带给出（不额外增加提问轮次）；用户说「auto / 你定」则直接采用首选。
- 用户已给平台但未点名风格：仍推荐候选并询问，不得直接采用首选——风格决定封面气质，不替用户默认（平台已知只是免掉平台提问，不免掉风格确认）。
- 风格库超过 3 个后：仍只推荐最匹配的 3 个，不展示全目录，除非用户要看全部。

## 加新风格

新建 `styles/{new-id}/META.md` + `STYLE.md`（照 `anthropic-research` 的 schema），在上表加一行，更新「内容 → 风格匹配」和平台推荐。
