# 封面提示词 Blueprint

本文件定义 `xenho-cover` 最终提示词的完整结构（封面形状）。`styles/{style-id}/STYLE.md` 是可复用的视觉风格原子；最终提示词必须把选定的风格原子**编译**进这个封面形状，读起来像一份完整独立的图像生成指令。

不要原样输出带空占位符的 blueprint。所有 `{...}` 都必须用派生字段和风格锚点填实。

## 最终提示词必须遵循的结构

```text
# {风格名}封面提示词

你是一位顶级封面艺术指导、编辑视觉设计师和字体设计师。

创作一张 {platform} 封面图，画幅比例 {ratio}，只生成一张最终成图。

整张封面必须使用「{风格名}」视觉风格。这不是装饰滤镜：标题、主体、背景、小字的每一个决定都要通过这个风格的视觉语言来实现。

## 内容输入

- 主视觉标题（A 层）：{短而有力的视觉标题}
- 完整标题（B 层，可与 A 层合并）：{完整标题}
- 副标题 / 小字（C 层，可留空）：{副标题}
- 一句话语境：{summary}
- 视觉主体：{visual_subject}
- 视觉隐喻：{metaphor}
- 情绪：{mood}
- 禁用元素：{banned_elements}

## 构图

- 主视觉中心：{主体图形及其位置}
- 标题位置：{标题落位，必须在纯色留白区}
- 辅助元素：{至多 1–2 个辅助形状及其作用}
- 阅读路径：{第一眼看到什么，第二眼理解什么}
- 留白与呼吸感要求

## 风格落地

{把风格锚点逐条改写成本次封面的具体画法：底色选哪个方案、墨线画什么、
剪纸形状是什么、隐喻如何用该风格的语汇实现}

## 字体与文字

- {标题字体、颜色、字号关系，按风格的排版规则写实}
- 汉字必须正确、完整、清晰可读，不得错字、缺笔画、裁切或过度变形。
- 汉字安全：中文只用标准比例的黑体 / 宋体 / 圆体；中文笔画不被任何图形、网点、贴纸覆盖；不拉伸、不压扁；{本风格的特殊字体，如有}只用于西文和数字。
- 文字总量：{按文字预算写实——内容文字（主标题 + 至多一行副标题）+ 本风格的微排版槽位（逐项列出）}。

## 文字白名单

{穷举画面内**已决定要画**的全部文字，每一处给出精确内容，分两组列出：
内容文字（主标题 1 + 副标题至多 1 行）；微排版（风格 META 里 `micro_type` 声明的槽位，
每一处给出精确内容，西文 / 数字为主）。没有 `micro_type` 的旧风格，点缀至多 2 处。
不得为了填满风格自带的槽位而增设文字位；风格提供但本次不启用的文字槽位，明确写「该位置无字」。
确实需要文字质感但无法给出精确内容的槽位，写「用短横线和波浪线示意文字的位置，不出现任何字母、数字或汉字」
（只写「不可辨读的占位质感」，图像模型会画出能读的 Lorem ipsum）。
不得存在未指定内容的文字位——空槽必然被图像模型自行填字}

## 色彩

{本次封面用到的精确色值和分配：底色、线条色、形状色，颜色总数上限}

整张图完全不透明：底色铺满整个画面到四边，不是透明底抠图，也不是去底产品图。

## 负面清单

避免：{风格特有禁用项}；PPT / 课程封面感；电商广告感；
信息图表；无关装饰；标题缺失或不可读；把文章原文写进画面。
（内容禁用元素已在「内容输入」段列出，此处不重抄——双份罗列会稀释权重）

## 终检标准

1. 一眼能看出是 {platform} 的 {ratio} 封面。
2. 第一眼读出主题，第二眼看懂隐喻。
3. 风格是画面的组织语言，不是贴上去的标签。
4. 主标题完整、汉字正确、清晰可读。
5. 只有一张成图，无多方案、无网格、无对比图。
```

## 编译规则

- 所有占位符必须填实，不许残留 `{...}` 或 `{{...}}`。
- 标题层合并：A 层与 B 层相同时，合并为一行「主视觉标题（A/B 层合并）：……」，构图段与文字白名单里该标题只出现一次，防止图像模型把同一句话渲染两遍。两者不同时，B 层是否入画是编译决策——入画则给出明确落位和与 A 层的字号关系；不入画则标注「仅作语义参考，不出现在画面」。
- **文字预算（硬上限），分两类算**：
  - **内容文字**：一个主标题 + 至多一行副标题。这是读者要读的部分，上限不变。
  - **微排版系统**：风格 `META.md` 里 `micro_type` 声明的槽位（期号、编号、年份、档案号、条形码、裁切标记、竖排小字、规格表、图签栏等）。它们是版面质感，不是信息——字号小、对齐严、以西文和数字为主，每一处都必须在白名单里给出精确内容，不得写成解释性句子，不得超出风格声明的槽位。高级的设计感很大部分来自这一层，不要为了「少字」把它砍掉。
  - 没有 `micro_type` 的旧风格，点缀至多两处（栏目标签 / 网址 / 样张行 / 期号数字，任选）。
  - 整段说明性句子（产品介绍、功能罗列、使用步骤）永远不入画——封面是入口，不是详情页。
- **微排版内容怎么填**：以风格 `micro_type` 的 `example` 为格式参考，按本次内容改写（期号、主题词的英文、年份）；作者本人的标识（`XENHO`、`辛禾`）可以进入名称、署名类槽位。不编造真实机构名、真实刊名、真实地址。
- **汉字安全（硬规则）**：中文只用标准比例的黑体 / 宋体 / 圆体；中文笔画不能被任何图形、网点、贴纸、遮罩覆盖；不靠拉伸、压扁撑满版面；风格里的特殊字体（热敏、点阵、像素、模版、打字机、书法）只给西文和数字。实测这几种情况汉字必错（压在网点上、被贴纸盖住、热敏字体、压扁巨字）。让每个汉字落在干净底色上；一字一格的排法准确率最高。
- **竖排遇西文就改横排**：标题里有西文词（App、AI、iPhone……）时不用竖排，风格要求竖排的改为同字体横排、放在原位置。图像模型会把竖排里的西文拆成单字母或乱断（实测「App」→「A / pp」）。
- **自有产品发布**：来源内容是作者本人的产品 / 工具 / 项目上线时，A 层直接用产品名做主体巨字，B 层金句降为副标题；产品名在提示词里给出精确拼写与大小写，并进终检标准逐字核对。第三方公司名、产品名与真实人名仍不入画。
- 字效安全距离：标题与图形融合的风格（字嵌入物体、被前景遮挡、随主体破坏）必须在构图段写明——破坏 / 遮挡效果与任何笔画保持至少一个字宽的缓冲距离，破坏只发生在字的周边，不发生在字身上。
- 风格锚点来自选定风格的 `META.md`（`style_anchors`、`cover_shape_adaptation`、`micro_type`、`must_preserve`、`avoid_when_applying_to_cover`）；`META.md` 没覆盖的视觉语言从 `STYLE.md` 补。
- 「终检标准」里加一条：微排版每一处内容与白名单逐字一致、没有多出的字。
- **不透明底（硬规则）**：「色彩」段末尾那句「整张图完全不透明……」每份都要保留。GPT image 遇到物件摄影类画面（小票、瓶子、便利贴）会自作主张输出透明底 PNG：底色整张丢失，只剩物件周围一圈半透明投影，上传后透明处变黑或变白（2026-10 热敏小票实测，横版 18%、方版 31% 的像素是透明的）。
- 不许把 `STYLE.md` 原文整段贴进来当第二部分，必须改写融合。
- 长文只进派生字段（标题层、一句话语境、隐喻），不进原文。
- 提示词默认用中文：Prompt 模式贴给 GPT Image 系列、Direct 模式默认走 `gemini-3.1-flash-image`，两者对中文提示词与中文字形的还原都已实测良好；用户明确要英文时，整份提示词输出英文。
- 最终提示词应比风格原子更长、更具体，因为它包含了封面形状、标题层级和内容适配。

## 公众号双画幅（3.35:1 = 2.35:1 横版 + 1:1 方版）

公众号后台只收一张封面，再在上面分别框选 2.35:1（订阅消息头条）和 1:1（转发卡片、文章列表、次条）。所以公众号交付一张 3.35:1 拼合图：左边是横版构图，右边是方版构图，两个框各自落在一张完整的设计上。没有模型能一次画出 3.35:1（gpt-image 最宽 3:1，gemini 在 21:9 之后直接跳到 4:1），所以要**编译两份提示词、分别出图，再用 `scripts/wechat_combine.py` 拼合**。

- **先定一组共享设计决定，再分别编译两份完整提示词**：风格、配色 hex、隐喻物件的具体描述（形状、材质、数量）、横版标题文字、方版标题文字（标题超过 8 个字时取的核心短语，在这里先定好）、字体描述、微排版内容。两份提示词各自独立、按上面的结构写全，都不提「另一张」，也不提「拼合」「左右两栏」。图像模型看不到另一张，一致性只能靠这些决定在两份里逐字相同。
- **横版（2.35:1）**：按风格 `cover_shape_adaptation` 的横版写法。
- **方版（1:1）**：从风格的**竖版（3:4）布局收紧**而来，因为方版和竖版更接近，横版硬裁成方的只会切掉标题。方版大多以缩略图尺寸出现，聊天卡片和文章列表旁边本来就会显示文章标题，所以：
  - 主视觉放大，占画面 50–60%，缩到 120px 宽还能一眼认出；
  - 文字只留主标题，超过 8 个字就只取核心短语（例：「我把待办 App 全删了」→「删掉待办」），不放副标题；
  - 微排版至多 1 处，选最能代表风格的那个槽位；
  - 不放缩小后看不清的细节（细线注释、多行规格表、小字段落）。
- 「终检标准」第 1 条分别写成「公众号头条的 2.35:1 封面」「公众号转发卡片的 1:1 封面」；两份各加一条：配色、物件、标题文字与共享设计决定逐字一致。
